# PT-BR: Moodle para Desenvolvedores

Este livro é um guia prático para quem deseja desenvolver para Moodle entendendo não apenas como criar um plugin, mas também como a plataforma funciona internamente, quais APIs devem ser utilizadas e quais decisões fazem diferença quando o código precisa continuar funcionando em produção.

Ao longo dos capítulos são abordados arquitetura, tipos de plugins, banco de dados, XMLDB, Forms API, Output API, segurança, arquivos, eventos, tarefas agendadas, cache, Web Services, módulos de atividade, autenticação, matrícula, testes automatizados, Git, integração contínua e manutenção entre diferentes versões do Moodle.

Os capítulos podem ser lidos em sequência, como um livro, ou utilizados individualmente como material de consulta durante o desenvolvimento.

[**Acessar o livro — Moodle para Desenvolvedores**](https://eduardokrausme.github.io/moodle-for-developers-book/pt_br/)

# EN: Moodle for Developers

This book is a practical guide for developers who want to build for Moodle while understanding not only how to create a plugin, but also how the platform works internally, which APIs should be used, and which architectural decisions matter when code has to keep working in production.

Across the chapters, the book covers architecture, plugin types, databases, XMLDB, Forms API, Output API, security, files, events, scheduled tasks, caching, Web Services, activity modules, authentication, enrolment, automated testing, Git, continuous integration, and maintenance across Moodle versions.

The chapters can be read in sequence as a book or used individually as a practical reference during development.

[**Read the book — Moodle for Developers**](https://eduardokrausme.github.io/moodle-for-developers-book/en/Chapter_01_Moodle_architecture.html)
