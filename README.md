# Moodle para Desenvolvedores

Este livro é um guia prático para quem deseja desenvolver para Moodle entendendo não apenas como criar um plugin, mas também como a plataforma funciona internamente, quais APIs devem ser utilizadas e quais decisões fazem diferença quando o código precisa continuar funcionando em produção.

Ao longo dos capítulos são abordados arquitetura, tipos de plugins, banco de dados, XMLDB, Forms API, Output API, segurança, arquivos, eventos, tarefas agendadas, cache, Web Services, módulos de atividade, autenticação, matrícula, testes automatizados, Git, integração contínua e manutenção entre diferentes versões do Moodle.

Os capítulos podem ser lidos em sequência, como um livro, ou utilizados individualmente como material de consulta durante o desenvolvimento.
